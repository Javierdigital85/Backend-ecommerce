 # e-commerce
 Aunque MongoDB soporta transacciones, PostgreSQL es más adecuado para un e-commerce, ya que ofrece transacciones atómicas más simples, robustas y naturales para manejar órdenes, pagos y stock.

 Las bases de datos como PostgreSQL usan ACID:
 
A — Atomicidad

Todo o nada

C — Consistencia

Los datos siempre son válidos

I — Aislamiento

Una compra no pisa a otra

D — Durabilidad

Lo confirmado no se pierde
